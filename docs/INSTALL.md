# Установка и запуск Runet Access (прототип)

> Инженерный прототип, **не plug-and-play**: установка человеком без технических навыков не проверялась
> (см. [LIMITATIONS.md](LIMITATIONS.md)). Нужны Windows 11 и установленный Google Chrome.

## Как это устроено

Один запуск = одно специальное окно Chrome. `RunetAccess.exe` запускает ядро sing-box на `127.0.0.1` и
отдельный Chrome со своим профилем, весь трафик которого идёт через ваш ключ. Ничего не устанавливается
в систему: нет расширений, режима разработчика, записей в реестр, системного прокси, TUN, служб.
Обычный Chrome и другие программы работают как раньше. Закрыли окно — ядро остановлено, конфиг с ключом удалён.

## Шаги

1. Распакуйте папку `runet-access` в любое место (например, `C:\Users\<имя>\RunetAccess`).
2. Дважды щёлкните **RunetAccess.exe**. Если Windows показала SmartScreen — «Подробнее» → «Выполнить в любом
   случае» (файлы не подписаны, см. ограничения).
3. В открывшемся окне вставьте ключ из Telegram → «Подключить» → впишите адрес сайта → «Открыть».

Данные программы: `%LOCALAPPDATA%\RunetAccess\` (профиль окна, зашифрованный ключ, если вы разрешили его запомнить).

Короткая проверка с реальным ключом: [MANUAL-CHECK.md](MANUAL-CHECK.md).

## Удаление

Удалите папку программы и (по желанию) `%LOCALAPPDATA%\RunetAccess\`. Больше ничего не менялось.

## Сборка из исходников (для разработчиков)

```powershell
.\scripts\build.ps1                 # докачивает Go и sing-box в .local\tools (по закреплённым хешам),
                                    # гоняет тесты, собирает dist\runet-access
. .\scripts\env.ps1; node tests\launcher-e2e.mjs   # сквозной тест в настоящем Chrome
```

Все кэши, инструменты, временные файлы и профили тестов лежат внутри корня проекта (`scripts\env.ps1`).
Тест запускает лаунчер с `RUNET_ACCESS_HOME` внутри корня и синтетическим сервером на localhost; реестр не затрагивается.

Переменные окружения лаунчера (для тестов): `RUNET_ACCESS_HOME`, `RUNET_CHROME_PATH`,
`RUNET_CHROME_EXTRA_ARGS`, `RUNET_PROBE_URL` (подмена адреса проверки страны), `RUNET_NO_DIALOG`,
`RUNET_EXPECTED_COUNTRY` (двухбуквенный код: страна, которую должна подтвердить проверка выхода; по умолчанию `RU`;
проверка остаётся настоящей и отклоняет несовпадение; нужна только для проверки иностранного тестового сервера).
