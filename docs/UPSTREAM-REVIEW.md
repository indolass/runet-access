## Вывод

MagicProxy подходит как основа: сценарий «ключ → локальное ядро → только выбранные домены
через прокси» в нём уже есть. Новый браузер и новый протокольный клиент не нужны.
Отсутствовало: простое окно для обычного человека, проверка страны выхода, кнопка
открытия сайта, понятные ошибки. Это добавлено поверх upstream (см.
[CHANGES-FROM-UPSTREAM.md](CHANGES-FROM-UPSTREAM.md)).

## `vendor-bin/magicproxy-host.exe~`

Файл 9 858 560 байт (PE, `MZ`) закоммичен в `01360be`, хотя README и `.gitignore`
утверждают, что бинарники в git не кладутся (шаблон `*.exe` не ловит `.exe~`).
Метаданные Go (`go version -m`, без запуска): Go 1.26.5, `vcs.revision=8de40b2…`,
`vcs.modified=true`. То есть это чья-то локальная сборка более старого, «грязного»
дерева. Наша сборка из `baf56b5` (Go 1.26.8) даёт другой файл; воспроизвести его из
SHA нельзя. **Вердикт: непроверенный бинарник, не запускался, не используется.**
Остаётся предупреждением об уровне гигиены репозитория upstream.
