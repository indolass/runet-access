# Таблица совместимости госсайтов

Универсальность архитектуры не означает «проверены все госсайты». Таблица ведётся по результатам
ручных проверок (личный кабинет проверяет Owner). Не записывайте в неё персональные данные, ключи,
номера документов и содержимое кабинетов.

Результат: PASS / FAIL / NOT TESTED. Для первого этапа нужны репрезентативные федеральные, региональные
и ведомственные сайты (муниципальные — по возможности).
