## Прогон 2026-10-07: ключ Outline `ssconf://` с префиксом (версия 0.5.0)

подтверждение **не записывается**; для Runet Access результат по Госуслугам с этим ключом остаётся FAIL (таймаут в автоматическом прогоне).
Повторный прогон и сравнение путей (почему там открывается, а здесь нет) не выполнялись и в задачу упаковки не входят.
