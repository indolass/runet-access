# Ручная проверка с реальным ключом (для Owner)

Состояние: **прототип**. Реальный ключ вводите только сами, только в окне расширения.
Не вставляйте его в чат, файлы, скриншоты и отчёты.

## Подготовка (один раз, примерно 5 минут)

1. Откройте `D:\AI-workspaces\runet-access\dist\runet-access\` (собирается `scripts\build.ps1`).
2. Дважды щёлкните **Install.cmd**. Он запишет одно значение реестра для вашего пользователя
   (`HKCU\Software\Google\Chrome\NativeMessagingHosts\com.runet_access.host`). Windows может показать
   предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае». Скрипт можно сначала посмотреть
   (`register.ps1`) или запустить без `-Apply`: он только покажет, что будет сделано.
3. Создайте в Chrome **отдельный профиль** (значок профиля → «Добавить» → «Продолжить без аккаунта»).
   Все шаги ниже — в нём. Обычный профиль не затрагивается.
4. В новом профиле откройте `chrome://extensions`, включите «Режим разработчика», нажмите
   «Загрузить распакованное» и выберите папку `...\dist\runet-access\extension`. Закрепите значок.
   Chrome при каждом запуске может напоминать, что включены расширения режима разработчика.

## Проверка

1. Нажмите на значок Runet Access → «Настройки сайта» → впишите адрес нужного сайта (`https://...`),
   при необходимости адреса страницы входа и статики (по одному в строке) → «Сохранить».
2. Вставьте ключ из Telegram в поле → **Подключить**.
   Ожидаемо: зелёная строка «Подключено. Выход подтверждён: RU», внизу три строки:
   «Выход через сервер» (RU и IP), «Остальной интернет» (ваш обычный IP, другой), «Сайт» (отвечает).
   - Если выход не RU или трафик идёт мимо сервера, подключение само отключится, и будет сказано, почему.
   - «Выход подтвердить не удалось» — это не успех: нажмите «Проверить ещё раз».
3. Нажмите **Открыть сайт**. Войдите и работайте руками. Вход, подпись и отправка отчётов
   не автоматизируются; отметьте для себя отдельно: открылся ли сайт / прошёл ли вход / работает ли подпись.
4. **Обычный интернет:** в соседней вкладке откройте `https://api.ipify.org` — должен быть ваш обычный IP.
   Другая программа (например, `curl https://api.ipify.org` в командной строке) тоже показывает обычный IP.
   Параметры Windows → Сеть → Прокси: «Использовать прокси-сервер» остаётся как было.
5. **Сбой:** в Диспетчере задач завершите `sing-box.exe` (из папки dist) при открытом сайте. Сайт не должен
   «тихо» открыться напрямую (расширение перезапустит ядро само в течение секунд).
6. Нажмите **Отключить**: статус «Отключено», сайты открываются как обычно. Закройте Chrome:
   в Диспетчере задач не должно остаться `sing-box.exe` и `runet-access-host.exe`.
7. Нажмите «Удалить» у ключа, если больше не нужен.

## Удаление

Дважды щёлкните **Uninstall.cmd** (удалит значение реестра и временную папку), затем удалите
расширение в `chrome://extensions` и при желании папку программы.

## Что сообщить

По каждому пункту: PASS / FAIL / NOT TESTED и что видно на экране (без ключа и без данных кабинета):
российский выход, открытие сайта, вход, подпись, отключение, обычный интернет.
