# Ручная проверка с реальным ключом (для Owner)

Состояние: **прототип**. Реальный ключ вводите только сами, только в окне Runet Access.
Не вставляйте его в чат, файлы, скриншоты и отчёты. Реестр, расширения и режим разработчика
не нужны: ничего в обычном Chrome и в системе менять не требуется.

## Запуск

1. Соберите (`scripts\build.ps1`) или возьмите готовую папку `D:\AI-workspaces\runet-access\dist\runet-access\`.
2. Дважды щёлкните **RunetAccess.exe**. Windows может показать предупреждение SmartScreen
   («Подробнее» → «Выполнить в любом случае»): файлы не подписаны.
3. Откроется **отдельное окно Chrome** со страницей Runet Access (профиль создаётся автоматически).

## Проверка

1. Вставьте ключ из Telegram → **Подключить** (флажок «Запомнить ключ» по желанию).
   Ожидаемо: зелёная строка «Подключено. Выход подтверждён: RU», ниже «Выход этого окна» (RU и IP) и
   «Обычное соединение (вне окна)» (ваш обычный IP — **другой**).
   - Страна не RU или трафик идёт мимо ключа: подключение само отключится и объяснит причину.
   - «Выход подтвердить не удалось» — это не успех: «Проверить выход ещё раз».
2. Впишите адрес нужного сайта → **Открыть** (откроется новая вкладка). Войдите и работайте руками.
   Вход, подпись и отправку отчёта программа не автоматизирует. Отметьте для себя отдельно: открылась ли
   страница / прошёл ли вход / нужная операция / работает ли подпись. Эту (первую) вкладку не закрывайте.
3. **Обычный интернет:** в вашем обычном Chrome или командной строке (`curl https://api.ipify.org`) виден
   ваш обычный IP. Параметры Windows → Сеть → Прокси остались как были.
4. **Сбой:** в Диспетчере задач завершите `sing-box.exe` (из папки dist). Окно на секунды теряет связь
   (страницы не открываются, напрямую они **не** грузятся), затем программа сама перезапускает ядро.
5. **Отключить:** окно остаётся без интернета вообще (так задумано); сайты напрямую из него не открываются.
6. **Закройте последнее окно Chrome.** В Диспетчере задач не должно остаться `sing-box.exe` и `RunetAccess.exe`.
7. «Удалить» у ключа стирает его с компьютера. Данные сессии сайтов остаются в профиле
   `%LOCALAPPDATA%\RunetAccess\profile` (удалить папку можно вручную).

## Что сообщить

По каждому пункту: PASS / FAIL / NOT TESTED и что видно на экране (без ключа и без данных кабинета):
российский выход, открытие сайта, вход, операция, подпись, сбой, закрытие. Для таблицы совместимости
([COMPATIBILITY.md](COMPATIBILITY.md)): URL, дата, результат, ограничения.
