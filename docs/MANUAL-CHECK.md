# Ручная проверка с реальным ключом (для Owner)

Состояние: **прототип**. Реальный ключ вводите только сами, только в окне Runet Access.
Не вставляйте его в чат, файлы, скриншоты и отчёты. Реестр, расширения и режим разработчика
не нужны: ничего в обычном Chrome и в системе менять не требуется.

## Запуск

1. Соберите (`scripts\build.ps1`) или возьмите готовую папку `D:\AI-workspaces\runet-access\dist\runet-access\`.
2. Дважды щёлкните **RunetAccess.exe**. Windows может показать предупреждение SmartScreen
   («Подробнее» → «Выполнить в любом случае»): файлы не подписаны.
3. Откроется **отдельное окно Chrome** со страницей Runet Access (профиль создаётся автоматически).

## Проверка

1. **Первый запуск.** Окно «Российские сайты — в отдельном окне». Вставьте ключ в поле «Ключ подключения» → «Подключиться»
   (флажок «Запомнить на этом компьютере» по желанию). Ожидаемо: вверху «Подключено через Россию», ниже плитки сайтов.
   - «Нет ключа?» раскрывает инструкцию и ссылки на двух ботов: кнопка «Открыть» открывает Telegram или обычный браузер,
     «Скопировать ссылку» кладёт адрес в буфер. Работает и до подключения.
   - «Выход не в России» / «Трафик идёт мимо ключа»: подключение само остановлено, сайты не открываются.
   - «Не удалось подтвердить страну выхода» — не вывод о ключе: нажмите «Повторить проверку».
   - «Сервер недоступен» — сервер ключа не отвечает: «Повторить» или «Заменить ключ».
2. **Сайты.** Нажмите на плитку (Госуслуги / Налоговая / Минюст) или впишите адрес в «Другой сайт» → «Открыть». Откроется
   одна новая вкладка этого же окна. Войдите и работайте руками: вход, подпись и отправку отчёта программа не автоматизирует.
   Отметьте отдельно: открылась ли страница / прошёл ли вход / нужная операция / работает ли подпись. Первую вкладку
   (управление) не закрывайте: в ней видно состояние подключения.
3. **Подробности.** «Подробности подключения»: страна и адрес выхода, ваш обычный адрес (должен отличаться), «Повторить
   проверку», «Скопировать сведения» (без ключа и сервера, адреса сокращены).
4. **Повторный запуск.** Закройте окно, запустите снова: ключ не спрашивают, показаны плитки и «Подключиться», само ничего
   не подключается. Нажмите на плитку: подключение → проверка → открытие сайта один раз.
5. **Настройки.** «Заменить ключ»: «Отмена» оставляет всё как было; ключ, не прошедший проверку, не затирает прежний
   сохранённый. «Удалить сохранённый ключ» спрашивает подтверждение.
6. **Обычный интернет:** в вашем обычном Chrome или командной строке (`curl https://api.ipify.org`) виден ваш обычный IP.
   Параметры Windows → Сеть → Прокси остались как были.
7. **Сбой:** в Диспетчере задач завершите `sing-box.exe` (из папки dist). Окно на секунды теряет связь (напрямую страницы
   **не** грузятся), программа перезапускает ядро и заново проверяет выход: статус на время проверки не «зелёный».
8. **Отключить:** окно остаётся без интернета вообще (так задумано).
9. **Закройте последнее окно Chrome.** В Диспетчере задач не должно остаться `sing-box.exe` и `RunetAccess.exe`.
10. Данные сессии сайтов остаются в профиле `%LOCALAPPDATA%\RunetAccess\profile` (папку можно удалить вручную).

## Что сообщить

По каждому пункту: PASS / FAIL / NOT TESTED и что видно на экране (без ключа и без данных кабинета):
российский выход, открытие сайта, вход, операция, подпись, сбой, закрытие. Для таблицы совместимости
([COMPATIBILITY.md](COMPATIBILITY.md)): URL, дата, результат, ограничения.
