# runet-access

Простой доступ к российским сайтам из-за рубежа: вставить ключ и подключить только браузер.

**Статус: локальный прототип специального браузера (не plug-and-play). Собирается и проходит автоматические проверки в настоящем Chrome на синтетическом сервере. Со вторым реальным ключом (VLESS + WebSocket + TLS) подтверждены российский выход и открытие публичных страниц Госуслуг, ФНС и Минюста; вход в кабинеты, электронная подпись и установка неподготовленным пользователем не проверялись.**

Цель — специальный браузер для Windows: открыть приложение, вставить ключ
из Telegram при первом запуске или замене, подключиться, зайти на нужный
сайт, вручную сдать отчёт и закрыть окно. Это отдельный инструмент для
эпизодических задач. Обычный браузер и остальные программы продолжают
пользоваться прежним интернет-соединением.

Профиль и маршрутизацию приложение настраивает само. Пользователю
не нужно разбираться в расширениях, портах и списках доменов.

Исследуем повторное использование [MagicProxy](https://github.com/MagicMaxLabs/MagicProxy).
Работоспособность с конкретным ключом, сайтом и электронной подписью пока
не подтверждена. Доступный российский сервер требуется отдельно.

## Для каких сайтов

Первый этап — российские государственные сайты всех типов, включая порталы
вне доменной зоны gov.ru. Цель — доступ из-за рубежа через российский выход.
Весь веб-трафик отдельного рабочего профиля направляется через прокси;
остальные профили и программы сохраняют обычное соединение.

После успешной проверки первого этапа планируется поддержка сайтов
государственных банков. Универсальный доступ ко всем сайтам пока не проверен.
