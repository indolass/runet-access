# runet-access

Простой доступ к российским сайтам из-за рубежа: вставить ключ и подключить только браузер.

**Статус: подготовка прототипа. Готового приложения пока нет.**

Цель — Windows-приложение или удобная оболочка готового решения для человека
без технических навыков: вставить ключ из Telegram, подключиться, проверить
российский выход и открыть нужный сайт. Остальные программы продолжают
пользоваться обычным интернетом.

Исследуем повторное использование [MagicProxy](https://github.com/MagicMaxLabs/MagicProxy).
Работоспособность с конкретным ключом, сайтом и электронной подписью пока
не подтверждена. Доступный российский сервер требуется отдельно.
